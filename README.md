# 观星知己 · Read & Know（readandknow.eu）

中国命理（八字 / 紫微斗数 / 六爻）免费排盘 + 分析师接单平台。
Python（FastAPI）+ SQLite，一台最便宜的云服务器就能跑。
命定，命运已定，只是何时发生而已。这是时间的意义

部署到网上请看 **部署教程.md**。

## 网站有什么

| 谁 | 能做什么 |
|---|---|
| 所有访客 | 免费排八字、紫微命盘、六爻摇卦；浏览分析师主页和真实评价 |
| 客户 | 注册 → 选分析师和服务 → 填出生信息或问题下单 → 按说明付款 → 收报告 → 留言追问 → 评价 |
| 分析师（抖音会员） | 凭邀请码注册 → 完善资料、上架服务和价格 → 站长审核后上线 → 接单、写报告、回复留言、看收入 |
| 站长（你） | 生成邀请码、审核分析师、确认收款、查看全部订单、结算、设置付款说明 / 服务费 / 公告 |

订单流程：待付款 → 客户点“我已付款” → 站长核对到账后确认 → 分析师接单 → 交付报告 → 客户评价。

## 第二版新增

- **三套风格**：夜观星空 / 水墨宣纸 / 敦煌壁画。访客在右上角切换；默认风格在「管理后台 → 网站设置」里选。
  样式在 `app/static/css/themes.css`，首页大图分别是 `templates/hero_night.html`、`hero_ink.html`、`hero_dunhuang.html`。
- **三种语言模式**：中英对照（默认）/ 中西对照 / 纯中文。界面翻译在 `app/content/ui_strings.py`，
  命理文案（天干、生肖、十神、主星、64 卦、合盘）在 `app/content/` 里，每条都有中 / 英 / 西三语。
- **悬停动画**：天干按五行有不同动画，地支悬停出现对应生肖（每只动物动作不同），十神也各有小动画；手机上点一下即可。
  动画在 `app/static/css/symbols.css`，符号组件在 `templates/_sym.html`。
- **不打分，只讲利弊**：每个符号、主星、十神都写「礼物」和「课题」。
- **八字合盘** `/hepan`：日主生克、互为十神、生肖与日支的合冲刑害、五行互补；不计算匹配度。分析师可以上架「合盘」服务。
- 网页字体来自 Google Fonts；在中国大陆访问时会自动换成系统自带的宋体 / 楷体，不影响使用。

## 在自己电脑上试运行

```bash
pip install -r requirements.txt
cp .env.example .env            # 然后改一下里面的管理员邮箱和密码
uvicorn app.main:app --reload
```
浏览器打开 http://localhost:8000 ，用 .env 里的管理员账号登录。

运行测试：`python tests/test_engines.py` 和 `python tests/test_flow.py`

## 排盘算法要点

**八字**：年、月柱以节气为界（立春换年），需要天文历表，所以用开源库 `lunar_python` 换算；
在四柱基础上算十神、藏干、纳音、十二长生、空亡、大运。五行能量：天干和地支本气各计 1 分、藏干余气各计 0.3 分。

**紫微斗数**（自己实现，并与开源排盘库 iztro 交叉验证：300 个随机生日比对十四主星、辅星、命宫、五行局、大限；另 200 个比对四化、身宫、命主身主、红鸾天喜，全部一致）：
1. 农历正月初一换年；晚子时（23 点后）按次日；闰月前 15 天算本月，后半月算下月。
2. 命宫 = (寅 + 月 − 1 − 时) mod 12，身宫 = (寅 + 月 − 1 + 时) mod 12。
3. 五虎遁定各宫天干 → 命宫干支纳音 → 五行局（水二、木三、金四、土五、火六）。
4. 紫微星：找最小的 x 使 (农历日 + x) 能被局数整除，商为 q；从寅宫数 q 格，x 偶数顺进 x 格、奇数逆退 x 格。
5. 天府 = (辰 − 紫微) mod 12（两星以寅申线对称）；其余主星按固定间隔顺逆排布。
6. 辅星（昌曲辅弼、魁钺、禄存羊陀、空劫、火铃、天马、红鸾天喜）与四化按口诀查表。

**六爻**：三枚铜钱掷六次（浏览器用密码学随机数），6/7/8/9 对应老阴/少阳/少阴/老阳；
用“逐爻翻转”生成京房八宫 64 卦的归属和世爻位置，纳甲装干支，按本宫五行配六亲，按日干配六神。
起卦时间用客户自己所在地的本地时间（影响六神和旬空）。
